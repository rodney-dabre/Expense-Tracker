# 💰 Expense Tracker

A simple full-stack web app that helps you track your daily expenses — add, view, and delete spending, and see your total in real time.

## 🚀 Live Demo
[View the live app here](https://your-live-url.onrender.com) <!-- replace with your actual Render URL -->

## ✨ Features
- Add new expenses with a title, amount, category, and date
- View all expenses in a clean, organized list
- See your total spending update automatically
- Delete expenses you no longer need
- Data is stored in a real database (SQLite)

## 🛠️ Built With
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express
- **Database:** SQLite (via better-sqlite3)
- **Deployment:** Render

## 🧑‍💻 How to Run It Locally

1. Clone this repository

git clone https://github.com/rodney-dabre/Expense-Tracker.git

2. Go into the project folder

cd expense-tracker

3. Install the dependencies

npm install

4. Start the server

node server.js

5. Open your browser and go to

http://localhost:3000
